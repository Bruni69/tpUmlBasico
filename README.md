 README: Trabajo Práctico de Programación Orientada a Objetos (POO)
 UML Implementación de Clases Java Basada en Modelado UML (9 Ejercicios).
 Descripción General.
 Este repositorio contiene la resolución del Trabajo Práctico de la asignatura Programación 2, enfocado en la aplicación práctica de los conceptos de modelado UML y su posterior implementación en clases Java.
 El proyecto se compone de nueve (9) ejercicios independientes, cada uno diseñado para consolidar diferentes aspectos de la POO, como encapsulamiento, utilizando clases y objetos.
 Tecnologías y HerramientasLenguaje de Programación: Java (JDK 21 o superior)Modelado: UML (Diagramas de Clases)IDE: NetBeans / IntelliJ IDEA / Eclipse.
 Sistema de Control de Versiones: Git🎯 Estructura y ContenidoEl trabajo se divide en 9 ejercicios. 
 La lógica principal de cada ejercicio se encuentra en las clases dentro del paquete src/main/java/ y se ejecuta a través de sus métodos main() correspondientes.
 Ejercicios Implementados.
 Concepto Central. 1_Clases y ObjetosModelado de una entidad básica.2_EncapsulamientoUso de getters y setters y atributos privados. 3_ComposiciónRelación "tiene un" (e.g., Coche y Motor). 
 Cómo Ejecutar el ProyectoPara ejecutar cualquiera de los ejercicios, siga estos pasos: Clonar el Repositorio.
 Abrir en el IDE:Importe el proyecto en su IDE de Java preferido (NetBeans, IntelliJ, etc.).
 Ejecutar: Localice la clase principal del ejercicio que desee probar (ejemplo: Ejercicio1.java, Ejercicio9.java).
 Haga clic derecho sobre la clase y seleccione "Run File" (Ejecutar Archivo). Cada clase principal (EjercicioX.java) contiene la lógica para instanciar los objetos y demostrar el concepto de POO abordado.
